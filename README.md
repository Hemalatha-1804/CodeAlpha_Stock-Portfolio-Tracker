# 📈 Stock Portfolio Tracker

## 📌 Project Overview

The Stock Portfolio Tracker is a simple Python application that helps users calculate the total value of their stock investments. Users enter stock symbols and quantities, and the program calculates the investment value using predefined stock prices stored in a dictionary.

This project was developed as part of the **CodeAlpha Python Programming Internship**.

---

## 🎯 Features

* Accepts stock names and quantities from the user.
* Uses a hardcoded dictionary to store stock prices.
* Calculates investment value for each stock.
* Computes the total portfolio value.
* Saves portfolio details to a text file.
* Simple and easy-to-understand implementation.
